C 盘空间安全清理 · Claude Code 操作指南

电脑越来越卡、C 盘飘红？用你已经装好的 Claude Code，安全地清出空间。

适用：Windows 10 / 11 · 面向非技术同事 · 内部参考 v1.0 · 2026-05-29
📌 建议优先用 HTML 版打开本指南（双击《C盘安全清理-Claude Code指南.html》）：网页版每段 Prompt 都有"一键复制"按钮，复制发给 Claude Code 更方便、不会漏字。本 PDF 仅供速览与打印参考。Prompt 原文也单独放在「Prompt原文（复制发给同事）」文件夹里。

⚠️ 使用前必读 · 慎重操作

本文档为 内部 AI 使用辅助参考，不是强制操作。磁盘清理涉及删除与移动文件，存在数据丢失风险。

1. 操作前请先备份重要资料（复制到 D 盘 / 公司网盘 / U 盘），并关闭并保存正在编辑的文件。

2. 对不确定的文件，一律保留不删——宁可占点空间，不冒丢文件的险。

3. 请严格按本指南的步骤走，不要让 AI 跳过"确认"环节直接删除。因个人操作产生的后果由操作者本人负责。

🛡️ 本指南的核心安全机制：隔离区，而不是直接删

我们不让 AI 永久删除任何东西。所有"疑似垃圾"都先被搬进一个 隔离区文件夹（例如 C:\_待删除观察区_20260529）。

你正常用电脑一周，如果什么都没坏、没发现少东西，再亲手清空这个隔离区。这样就算 AI 判断错了，文件也还在，随时能拿回来。

📑 目录 · 你属于哪种情况？

  1. 所有人第一步：先做"空间体检"
    只看不动，让 CC 告诉你空间被谁占了、能安全清多少
  2. 情况一：有 D / E 盘 → 把日常文件搬到 D 盘
    最有效，一劳永逸。先复制后验收，原件进隔离区
  3. 情况二：只有一个 C 盘 → 安全瘦身（不搬盘）
    交给 Windows 自带工具清系统垃圾 + 大文件传云/外接
  4. 进阶：清"AI/开发工具"留下的缓存
    装过 ccusage 等命令行工具的人，可多清几个 GB
  5. 安全护栏总则 + 红线清单（绝不能碰）
    所有操作都要守的 7 条铁律，以及永远不许动的文件
  6. 收尾：验收 + 一周后清空隔离区
    怎么确认搬过去的文件都能打开、没丢东西
📌 怎么用这份指南（和装 ccusage 一样简单）
在任意一个文件夹里打开 Claude Code，把对应步骤里深色框中的整段文字复制发给它（点右上角"复制"按钮）。它会用大白话一步步带你做，每一步都会停下来等你确认。建议顺序：先做第 1 步体检，看完结论再决定走情况一还是情况二。
1所有人第一步：先做"空间体检"
不删、不移、只体检。目的是搞清楚——C 盘到底被什么占满了，哪些能安全清、哪些碰不得。看完这份清单，你才知道自己该走情况一还是情况二。
📋 复制这段发给 Claude Code（第 1 步 · 所有人）
你是我的电脑空间体检助手。我的 C 盘快满了、电脑很卡。这一步请你【只体检、不删除、不移动任何文件】，把我当成完全不懂电脑的人，全程用简单中文。

请按顺序帮我：
1. 先确认我的 Windows 版本，并列出我电脑上有哪些磁盘（是只有 C 盘，还是还有 D 盘、E 盘？各自还剩多少空间？）。
2. 扫描 C 盘，找出最占空间的"前 20 个文件夹/文件"，做成一个清单给我看，每一项标明：名字、它在哪、占多少 GB、它大概是什么。
3. 把每一项归到三类并用颜色或符号标清楚：
   - ✅【可以安全清理的垃圾】：临时文件、回收站、各种软件缓存、下载文件夹里的旧安装包等；
   - 📁【我的重要文件】：文档、图片、视频、桌面文件等（这些只能搬家，不能删）；
   - ⛔【系统/程序文件，绝对不能动】：Windows、System32、Program Files 等。
4. 给我一句话体检结论：大概能安全清出多少 GB；以及建议我走哪条路——
   (A) 我有 D/E 盘，建议把大的个人文件搬过去；
   (B) 我只有 C 盘，建议原地瘦身。

⚠️ 这一步你【只许看、只许报告，一个文件都不许删、不许移、不许改】。等我看完清单，会再单独告诉你下一步做什么。
为什么先体检：不先看清楚就动手，是误删的头号原因。体检阶段 AI 一个文件都不会碰，零风险，但能帮你把"垃圾"和"重要文件"分清楚。

2情况一：有 D / E 盘 → 把日常文件搬到 D 盘
这是最有效、最一劳永逸的办法：把占地方的个人文件（项目、资料、下载、桌面大文件）整体搬到 D 盘，C 盘立刻松一大截，以后也不容易再满。
关键安全做法：先复制、再验收、确认无误后原件才进隔离区——绝不"剪切了就删"。
📦 复制这段发给 Claude Code（情况一 · 搬家到 D 盘）
你是我的"文件搬家助手"。我有 D 盘（如果实际是 E 盘等，请按我的盘来）。我想把 C 盘里占地方的个人文件搬到 D 盘，给 C 盘腾空间。把我当成完全不懂电脑的人，全程用简单中文，每一步都停下来等我确认，绝不自作主张。

请严格按这个"先复制、后验收、再隔离"的安全流程做，【任何时候都不要直接永久删除文件】：

1. 先和我一起确认"搬哪些"。给我列出建议搬到 D 盘的个人文件夹（比如：我的"下载/Downloads"、"文档/Documents"里的大文件、桌面上的大文件、我自己的项目或资料文件夹）。明确告诉我每个有多大。⛔ 不要动 Windows、Program Files、AppData 这些系统/程序文件夹。等我勾选确认要搬哪些。

2. 在 D 盘建一个清楚的目标文件夹（例如 D:\我的文件\），把我确认的内容【先复制过去，不是剪切】，原件先原地不动。

3. 复制完做【三项验收】并把结果告诉我：
   - 数量核对：新位置的文件数量和原来一致吗？
   - 大小核对：总大小一致吗（差异是否在正常范围）？
   - 抽查打开：随机挑 2~3 个文件（比如一个 Word、一个图片、一个 PDF）实际打开看看，确认在新位置能正常打开、没损坏。
   把这三项结果列给我看，让我确认"搬过去的都好"。

4. 我确认无误后，【不要删原件】，而是把 C 盘的原件【移动到一个隔离区文件夹】，名字带上今天日期，例如 C:\_待删除观察区_今天日期\。告诉我这一步清出了多少空间。

5. 关于改"默认下载/保存位置"（让以后的新文件直接存到 D 盘）：这一步有点专业，请你【用文字一步步带我手动点】Windows 自带的官方方法（在文件夹上点右键→属性→"位置"标签→移动），不要用脚本替我乱改系统设置——官方方法最安全，Windows 会自动更新所有关联。

6. 最后给我一句话总结：搬了哪些、清出多少空间、隔离区在哪、以及提醒我"一周后没问题再亲手清空隔离区"。

⚠️ 全程铁律：先复制不剪切、验收通过才动原件、原件进隔离区不直接删、不碰系统文件夹、遇到"同意/授权"弹窗才叫我。
💡 为什么"先复制后验收"，不直接剪切？
剪切（移动）一旦中途出错或文件损坏，原件可能已经没了。先复制 → 验收数量/大小/能不能打开 → 确认好了 → 原件再进隔离区，等于全程都有"后悔药"。
3情况二：只有一个 C 盘 → 安全瘦身（不搬盘）
没有别的盘可搬，思路就变成两条：① 清掉系统/软件垃圾（交给 Windows 官方工具最稳）；② 把占地方的大文件传到云盘或外接硬盘。同样全程不永久删。
🧹 复制这段发给 Claude Code（情况二 · 只有 C 盘瘦身）
你是我的"C 盘瘦身助手"。我的电脑【只有一个 C 盘】，没有别的分区，所以不能搬到别的盘。我想安全地清出空间。把我当成完全不懂电脑的人，全程用简单中文，每一步停下来等我确认。

请按这个安全顺序帮我，【全程不要永久删除我的个人文件】：

1. 系统垃圾——优先用 Windows 自带官方工具（这比你手动删系统文件安全得多）：
   - 带我打开"存储感知 / Storage Sense"（设置→系统→存储），帮我看"临时文件"里可以清理的项目（临时文件、Windows 更新残留、缩略图缓存、回收站等），告诉我各能清多少，让我勾选确认后再清。
   - 再带我用"磁盘清理 / Disk Cleanup"做一次（必要时用"清理系统文件"）。
   一步步用文字带我点，不确定的项目【默认不勾、先问我】。

2. 软件缓存：列出占地方的浏览器缓存、聊天软件（如微信/企业微信）的本地缓存、以及其它明显的缓存文件夹，告诉我各有多大、清了有什么影响（比如要重新登录吗），让我决定清哪些。

3. 大文件处理：找出"下载/Downloads""文档""桌面"里最占地方的大文件和旧安装包（.exe/.zip 等）。对每一类：
   - 旧安装包、明显没用的 → 移到隔离区文件夹 C:\_待删除观察区_今天日期\（不要直接删）；
   - 我还要的重要大文件 → 提示我传到公司网盘 / OneDrive / 外接硬盘，传完确认能打开后，再把本地原件移进隔离区。

4. 不用的软件：列出体积大、我可能不用的已安装软件，让我自己挑要不要卸载（卸载请走 Windows"应用"设置里的正规卸载，不要手动删文件夹）。

5. 最后给我总结：清出了多少空间、隔离区在哪、还有哪些大文件建议我传云。并提醒我"一周后没问题再亲手清空隔离区"。

⚠️ 铁律：系统垃圾优先用 Windows 自带工具；个人文件先进隔离区不直接删；⛔ 绝不碰 Windows、System32、Program Files、AppData 里不认识的东西；遇到"同意/授权"弹窗才叫我。

补充：如果你发现我这台电脑空间长期紧张，请最后顺便建议我：是否值得让 IT 帮忙加一块硬盘 / 分一个 D 盘，从根上解决。
给只有 C 盘的同事的话：这种情况清出来的空间有限，治标。如果你的工作文件越来越多，最稳的办法是请 IT 加块硬盘或分个 D 盘，再按"情况一"搬家。日常资料多用公司网盘，也能让本机一直保持轻快。
4进阶：清"AI / 开发工具"留下的缓存
如果你装过 ccusage、Node.js、Python 这类命令行工具，它们会在 C 盘悄悄堆下载缓存和依赖包，少则几百 MB、多则十几 GB。这些都能安全清理（用到时会自动重新下载）。不用命令行的同事可跳过本节。
⚙️ 复制这段发给 Claude Code（进阶 · 清开发缓存）
你是我的"开发缓存清理助手"。我装过命令行工具（比如 Node.js / ccusage / Python 等），听说它们会在 C 盘堆很多缓存。请帮我安全地清掉这些缓存。用简单中文，每一步先告诉我"这是什么、清了有没有影响"，再等我确认。

请帮我：
1. 先体检：找出并告诉我这些常见缓存各占多大（不要清，先报告）：
   - npm 缓存、npx 缓存（通常在 %LocalAppData%\npm-cache）；
   - 各处的 node_modules 依赖文件夹（如果我有代码项目）；
   - pip / Python 缓存；
   - 其它明显的工具缓存。
2. 解释清楚：这些缓存清掉【不会丢我的文件和代码】，只是下次用到时工具会重新下载，顶多慢一点点。确认我理解后再继续。
3. 清理时优先用工具自带的官方命令（例如 npm 用 `npm cache clean --force`），而不是直接乱删文件夹。
4. 对于体积大的 node_modules：只清理我【确认已经不用的旧项目】里的；正在用的项目不要动。不确定的，先问我。
5. 完成后告诉我一共清出多少空间。

⚠️ 铁律：先报告后清理、只清缓存和确认没用的依赖、不碰我的源代码和文档、遇到拿不准的先问我。
放心点：缓存（cache）和依赖包（node_modules）的本质就是"可以再生"的临时数据，清掉它们不会丢你写的东西。这也是为什么很多人装完命令行工具后 C 盘莫名变小——缓存堆起来了。
5安全护栏总则 + 红线清单
无论走哪种情况，这 7 条铁律都要守住。它们已经写进了上面每一段 Prompt 里，这里集中列出，方便你心里有底、也方便你检查 AI 有没有"偷工减料"。
✅ 七条安全铁律
  • 先备份：动手前，把真正重要的文件先复制一份到 D 盘 / 公司网盘 / U 盘。
  • 先体检、后确认、再执行：永远先让 AI 列清单，你逐项看过、确认，才允许它动手。不接受"我帮你都清好了"。
  • 不永久删，用隔离区：要清的东西先搬进 C:\_待删除观察区_日期，正常用一周没事，再亲手清空。
  • 搬家先复制后验收：复制到新位置 → 核对数量 + 大小 + 随机打开几个文件 → 确认无误 → 原件才进隔离区。
  • 系统垃圾交给 Windows 自带工具：存储感知 / 磁盘清理，比让 AI 手动删系统文件安全得多。
  • 分批，不一把梭：一次处理一类，做完确认没问题再做下一类。
  • 让 AI 说人话、按弹窗叫你：全程大白话，只有需要你点"同意 / 授权"时才打扰你。
⛔ 红线清单：这些文件夹永远不许删、不许移
  • C:\Windows（尤其 System32）—— 系统核心，动了开不了机。
  • C:\Program Files 和 C:\Program Files (x86) —— 已装软件，要卸载走"应用"设置正规卸载。
  • C:\ProgramData 和 C:\Users\你的用户名\AppData 里你不认识的文件夹 —— 软件的运行数据，乱删会让软件出错。
  • pagefile.sys / hiberfil.sys —— 系统虚拟内存 / 休眠文件，不要手动删。
  • C:\Users 文件夹本身 —— 不要整个搬走，只能用官方方法搬里面的"文档/下载"等子文件夹。
  • Windows.old —— 删了就不能回滚到旧版本系统；要删请通过"磁盘清理"删，并确认你不打算回退。
  • 任何你不认识、又不确定的文件 —— 不确定就保留，问一句不丢人。
如果 AI 想跳过确认直接删，或要碰上面红线里的东西：直接回它"停，先列清单给我确认，红线文件不要动"。你有权随时喊停。
6收尾：验收 + 一周后清空隔离区
清理完不是结束。最后这一步确保"东西都还能用、没丢"，并在确认安全后真正释放空间。
当天：快速验收
  • 打开你常用的几个文件 / 软件，确认都能正常打开、没报错。
  • 如果做了搬家：去 D 盘新位置随便点开几个文件，确认能打开、不是空的。
  • 重启一次电脑，确认开机正常、桌面和软件都在。
一周后：清空隔离区，真正释放空间

这一周里如果没发现任何文件不见、没有软件报错，说明隔离区里的都是真垃圾。这时可以把这段发给 Claude Code，或自己手动删除那个 _待删除观察区_日期 文件夹：

🗑️ 复制这段发给 Claude Code（一周后 · 清空隔离区）
一周前我做过 C 盘清理，把要删的东西都先放进了一个隔离区文件夹（名字类似 C:\_待删除观察区_日期）。这一周我正常用电脑，没发现少东西、没软件报错。

请帮我：
1. 先找到这个隔离区文件夹，告诉我它在哪、里面一共多少东西、占多少空间。
2. 把里面的内容大致列给我看一眼（让我最后扫一眼，确认没有我其实还想要的）。
3. 我确认后，再删除这个隔离区文件夹，释放空间。删完告诉我清出了多少。

⚠️ 只删这一个隔离区文件夹，别的什么都不要动。删之前一定先让我看一眼清单。
到这一步你就完整地、安全地清完了。整个过程没有任何一次"不可挽回的永久删除"——每一步都有后悔药，这正是这套方法的意义。
