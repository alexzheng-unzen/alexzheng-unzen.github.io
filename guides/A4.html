Claude 信息备份指南 · 全员版

最近社区有一波账号误封。这份指南只解决一件事：万一哪天号没了，你的对话、代码、资料别跟着一起没，换个号还能接着干。原则很简单——能自己安全做的就做，碰数据安全的发到 token 燃烧营一起讨论，不自己瞎搭备份管道。

先看懂一件事：你的数据只有两个"家"

想清楚这点，下面做什么就不会乱——所有平台的数据，无非落在这两个家之一。
🟢 本地（在你电脑硬盘上）
  • Claude Code 终端版的 ~/.claude 文件夹（你全部的对话记录＋配置）
  • Claude Code 帮你写出来的代码 / 文档
特点：不绑账号 → 封号也带不走，换个号照样能读。
🔴 云端（在 Claude 的服务器上）
  • claude.ai 网页里的对话、Projects 项目
  • 桌面 App（Mac / Windows 版）里的对话
    ——它只是网页的"壳"，数据和网页同一片云
特点：绑账号 → 号一封，这部分立刻就没。
👉 "备份"就两个动作：① 把云端那部分搬出来（搬到公司管控的地方）；② 让本地那个文件夹多一份副本。下面按你的情况分别说。

⚠️ 先划红线：内容分密级，敏感的不外流

咱们是健康险行业，客户的病、钱、证件信息属于"敏感个人信息"。备份时先分清：能共享的才进飞书；敏感的只放公司受控的地方。拿不准 → 一律当敏感处理。
密级包括哪些（保险 / 健康场景）能放哪
🔴 高敏 客户姓名＋身份证 / 手机 / 住址、病历 / 体检 / 理赔 / 健康数据、保单与赔付明细、银行卡 / 支付信息、未公开的财务·合同·商业机密、各种密码 / 密钥 只放公司指定的受控位置（工作机指定盘 / 公司网络盘等）；不上任何云、不进飞书、不外发
🟡 中 内部流程 / 话术、未公开的项目资料、不含个人信息的内部汇总 团队飞书（仅内部可见）可以；公开渠道不可
🟢 低 公开资料、通用 prompt 模板、已发布的内容 随便存、可共享
🧭 一句话判断：内容里只要带"某个具体的人是谁 ＋ 他的健康 / 钱 / 证件"，就按 🔴 高敏处理。拿不准就当高敏，没人会怪你太小心。
💡 最上游、最有效的一招：一开始就别把客户原始敏感数据喂给 AI。要用先脱敏——去掉真实姓名 / 证件号，用"客户 A""保单 X"代替。没进过 AI 的数据，根本不用操心怎么备份它。

账号：公司 Team云端对话怎么备

目标＝被封也能换号照用。Team 有管理员能给你重开座位（seat），续命相对容易。
✅ 你要做的其实就一件事：重要的 Prompt / 对话结论，当场复制进飞书团队知识库（仅非敏感内容）。知识进了飞书就不绑在你这一个号上——你号出问题，内容还在，谁都能接着用。
⚠️ 客户 / 病历 / 理赔 / 财务等敏感数据别进飞书，按上面「红线」放公司受控位置。
💡 封号后怎么续：① 找管理员重开座位；② 重要内容已在飞书，新号直接接着用；③ 如果你也用 Claude Code，本机的 ~/.claude 不绑号，换号能无缝读回（见下方「本地」部分）。

账号：个人 Pro·Max云端对话怎么备

和 Team 的区别：没有管理员兜底——号没了没人帮你恢复，全靠你自己手里那份。所以官方导出对你更要紧。
🔴 第一步：用官方功能做一次"全量导出"。你若从没备份过，云端那堆对话现在是"裸奔"状态。
路径（已核实）：点左下角你的首字母头像 → Settings 设置 → Privacy 隐私 → Export data 导出数据，提交后等邮件里的下载链接（网页版或桌面 App 都行，手机 App 不行）。
几个坑：① 导出是 JSON 数据文件（留档用）；② 链接 24 小时过期，过期重导即可；③ 不含 Claude 的"记忆(memory)"；④ 导出的数据不能再导回到另一个个人账号——所以导出主要是"留底查阅"，真正"换号无缝接着干"靠的是本地 ~/.claude（见下方）。
⚠️ 导出的 JSON 包含你全部对话，本身就是敏感件：下载后别留在「下载」文件夹裸着，挪到公司受控位置；里面若有客户敏感内容，按红线处理、必要时发到 token 燃烧营讨论。
💡 日常：重要对话当场复制到本地文档（记事本 / Word / Obsidian）；非敏感的也可进飞书。每隔一段时间再导出 1 次兜底。

账号：两个都有先看这条，再看下面两块

🔀 你有两个账号，两边都要照顾：工作内容走 Team 账号 → 存飞书（仅非敏感）；个人内容走 Pro 账号 → 官方导出。下面「公司 Team」和「个人 Pro·Max」两块都已为你显示，各看各的。
💡 一个省力的真相：不管你用哪个账号登录 Claude Code，对话历史都堆在同一台电脑的同一个 ~/.claude 里。所以本地只要备份一次，两个账号的终端历史就一起保住。

系统：Windows本地 ~/.claude 怎么备份

最值得备份的是 Claude Code 的 ~/.claude 文件夹（完整路径＝C:\Users\你的用户名\.claude）。它不绑账号，封号后新号直接读它续命。不上任何云，按下面顺序来：
✅ 第一步先确认：公司是否已经在自动备份你的工作电脑（或用户目录）？不清楚就发到 token 燃烧营问一声。如果有，你什么都不用做——只要确认 C:\Users\你的用户名\.claude 在备份范围内即可。这是最省心的方式。
如果公司没有统一备份，自己给它在另一块盘留副本（U 盘 / 移动硬盘 / 电脑的第二块硬盘，不是云）：
把这行命令存成 backup.bat
桌面新建记事本，粘进下面这行（把 D:\claude-backup 改成你那块盘的实际盘符路径），另存为 backup.bat（保存类型选"所有文件"）： robocopy "%USERPROFILE%\.claude" "D:\claude-backup" /E /R:1 /W:1 /XD node_modules 意思：把 .claude 文件夹，每次只复制有变化的部分，备到 D 盘（或你的 U 盘 / 移动硬盘）。
（%USERPROFILE% 不用改、命令会自动找到你的用户文件夹；你只要把 D:\claude-backup 换成你那块盘。）
用"任务计划程序"让它每天自动跑
开始菜单搜「任务计划程序」 → 「创建基本任务」→ 取名 → 触发器选「每天」 → 操作选「启动程序」指向 backup.bat → 完成。
⚠️ 关键一步：建好后双击该任务 → 「设置」选项卡 → 勾上「错过计划开始后，尽快启动任务」。否则到点电脑没开机，这次就悄悄不跑了。
验收 ＋ 一次"能不能还原"检查
打开 D:\claude-backup，看文件"修改日期"是今天 ✅ 在跑；再随便打开里面一个文件确认能读出内容（不是空壳）。备份要能还原才算数。
⚠️ U 盘 / 移动硬盘别一直插着不管：它和电脑放一起，电脑丢 / 进水就一起没了。理想是另存一处。敏感数据的异地备份与加密别自己折腾——需要的话发到 token 燃烧营一起讨论。

系统：Mac本地 ~/.claude 怎么备份

最值得备份的是 Claude Code 的 ~/.claude 文件夹（完整路径＝/Users/你的用户名/.claude）。它不绑账号，封号后新号直接读它续命。Mac 上有现成的好办法，全程不上云：
✅ 第一步先确认：公司是否已在自动备份你的工作电脑？不清楚就发到 token 燃烧营问一声。有的话确认 ~/.claude 在范围内，你就不用额外做。
✅ 自己做的首选：开启 Time Machine（几乎零操作）。系统设置 → 通用 → Time Machine → 接一个移动硬盘并选它。开启后它每小时自动备份整台电脑，~/.claude 默认就被包含，不用单独设。
注意：它备到本地外接硬盘、不上云；防的是"电脑坏 / 丢"，而封号时本地文件本来就还在——两头都保。
⚠️ Time Machine 要定期把那块硬盘接上才会备（笔记本平时不插＝没在备）。敏感数据的加密与异地存放别自己折腾，需要的话发到 token 燃烧营讨论。

📦 三类数据，三种备法（别搞混）

和 Claude 有关的东西其实分三类，备法各不同。看清这张表，就知道下面那个 Prompt 管的是哪部分、没管的又靠什么补。
哪类数据封号会不会丢怎么备
① claude.ai 网页对话 / Projects 项目 🔴 会！号一封立刻没 官方导出 Export（个人）/ 存飞书（Team）——见前面「云端对话怎么备」
② Claude Code 终端对话历史（就是 ~/.claude 文件夹） 🟢 不会（在本地、不绑号）但硬盘坏 / 误删会丢，且云端没有任何副本 下面这个 Claude Code Prompt / robocopy / Time Machine
③ 本地项目代码 / 文档 🟢 不会（本来就在你硬盘上） git 私有仓库（顺带还能回滚被 AI 改坏的代码）
👇 下面这个 Prompt 只解决 ② 和 ③（本地）。① 网页那部分它备不了——号一封就没，务必另用前面的官方导出。两者各管一段，缺一不可。

🤖 懒人版：把本地备份直接交给 Claude Code 跑

你们大多在用 Claude Code——与其手动敲命令，不如把整套本地备份丢给它自己做。把下面这段粘进 Claude Code、回车即可，它会全程问你、用大白话汇报。
⚠️ 它备份的是本地 ~/.claude 和代码；claude.ai 网页对话是云端，Claude Code 备不了，那部分用前面的「官方导出」。
请帮我备份 Claude Code 的本地数据，按下面要求做，每一步用大白话告诉我你在做什么： 1. 先判断我的系统是 Windows 还是 Mac，找到我的 ~/.claude 文件夹（Windows 在 C:\Users\我的用户名\.claude，Mac 在 /Users/我的用户名/.claude），并告诉我它有多大。 2. 问我要把备份放到哪个【本地】位置（比如另一块硬盘 D:、一个 U 盘 / 移动硬盘的盘符，Mac 上的外接硬盘）。 ⚠️ 绝对不要备份到 OneDrive、iCloud 等任何云盘 / 同步盘；只能放本地物理盘。如果我给的路径是云盘，请提醒我并停下。 3. 用系统自带工具做"只复制、不删除原件"的备份，复制到我指定位置下的 claude-backup 文件夹： · Windows 用 robocopy，排除 node_modules； · Mac 用 rsync，排除 node_modules。 4. 备份完成后做验收并告诉我结果：源和目标的文件数量 / 大小是否一致，并随机打开备份里的一个文件确认能读出内容（不是空壳）。如有文件因正被占用没复制成功，如实告诉我。 5. 顺便看一下我电脑上 Claude Code 写过的代码 / 文档项目：如果还没用 git 备份，告诉我哪些值得加 git——但先别自动 push 到任何外部仓库，等我确认。 6. 最后问我：要不要把这个备份设成【每天自动跑一次】？ · 要的话，Windows 帮我建一个"任务计划程序"任务并勾上"错过后尽快运行"；Mac 给我一条能加进定时任务的命令。 · 全程不要把任何数据传到云端，也不要帮我加密（加密的事另外处理）。 请用中文回复，每做完一步简短说一句结果。
💡 它只会"复制"不会删原件，给的目的地也只认本地盘——放心跑。跑完它还会问你要不要设成每天自动。

如果你会用 Claude Code 写代码 / 文档

产出本就在本地项目里，配上 git 就有了带历史版本的备份。
💡 用 公司的私有 git 仓库（GitHub / GitLab / Gitee 企业版，有没有可在 token 燃烧营问一声，别用个人 GitHub）：项目里 git init → 连私库 → 习惯性 commit + push。
两条铁律：① 绝不把密钥 / 客户数据提交进去（一旦 push 很难彻底删干净）；② 仓库必须是私有。
验收：打开私库网页能看到今天的提交 = 成功。

✋ 这些别自己 DIY，发到 token 燃烧营一起定

下面几件事弄不好会"以为安全其实裸奔"或"加密后自己也打不开"，建议发到 token 燃烧营一起讨论、对齐统一口径：
① 整机 / 用户目录的自动备份——异地备份（在另一处也存一份）别各自捣鼓，在 token 燃烧营对齐公司是否已覆盖你的电脑。
② 敏感数据的加密存储与"恢复密钥"保管——加密了却丢了密钥＝数据永久打不开，密钥必须由公司托管。
③ 公司统一的备份落点（受控网络盘 / 加密移动盘等）——别各自往私人云盘搭管道。
④ 账号被封后的申诉 / 重开座位——Team 账号找管理员，个人账号走 Anthropic 官方申诉。

大白话名词卡（看不懂上面的词？点这里展开）
~/.claude 是什么？Claude Code 终端版在你电脑上的"老巢"文件夹，存着你全部对话记录和配置。~ 指你的个人目录——Windows 上完整路径是 C:\Users\你的用户名\.claudeMac 上完整路径是 /Users/你的用户名/.claude。它在本地、不绑账号，备份它＝换号能续命的关键。
robocopy 是什么？Windows 自带的智能复制工具，不用安装。只复制有变化的部分，每天自动跑也很快，适合做定时备份。
Time Machine 是什么？Mac 自带的"时光机"自动备份。接一块移动硬盘选上，它每小时自动备整机（含 ~/.claude），备在本地硬盘、不上云。
git / 私有仓库 是什么？git 是"带时间戳的存档器"。把代码连上公司私有仓库后，每次"提交并推送"就在仓库存一个版本，哪天的样子都能找回。私有＝只有授权的人能看。
飞书知识库 是什么？咱们团队飞书里的文档 / 知识库空间。把非敏感的 Prompt、结论存这里＝全团队都能看、不绑某个号，谁的号出问题都不影响大家。
官方导出（Export data）？Anthropic 提供的"打包下载我账号数据"功能，导出是 JSON 文件。申请制：点完等邮件发链接（24h 过期），不实时。个人号在 设置→隐私 里点；Team 成员一般没这入口，存飞书即可。
"公司受控位置"指什么？由公司管理、能审计、人走了能收回的存储（如工作机指定盘、公司网络盘）。不是你的个人 OneDrive / iCloud / 私人网盘。放哪不确定就发到 token 燃烧营讨论。
🎯 诚实底线：没有 100% 完美的备份。目标很朴素——不是"绝对不丢"，而是"封了也不丢、换号能续上"。 对绝大多数人，做到三件事就躲过了最惨的"全没"：① 重要对话当场存好（非敏感进飞书、敏感进公司受控位置）；② 给本地 ~/.claude 设一份不上云的备份（或确认公司已覆盖）；③ 碰加密、整机备份、敏感外发这类事，发到 token 燃烧营一起讨论。
