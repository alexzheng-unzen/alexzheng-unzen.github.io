1. 这本手册做什么

你已经装了 Claude Desktop。这本手册带你 15 分钟内拿到下面几件事：

  • Chat / Cowork / Code 三个模式怎么选，避免用错工具浪费时间
  • Opus / Sonnet 怎么切换 + Plan Mode 怎么用，把 Team plan 的 Opus 额度用在刀刃上
  • 5 分钟装好这套 Skill 包 + 安全护栏，过程中你只需要复制粘贴一两句话
  • 装完之后你得到的保护和预设，以后哪些事你不再需要担心
  • 4 个让 Claude 出好活的核心技巧
  • 10 个为你预装的 Skill + 如何自己造一个

读完时间：完整 15 分钟，只看红色护栏章节 + 速查卡 5 分钟。

2. Chat / Cowork / Code — 三个模式怎么选

Claude Desktop 把三种使用方式合在了同一个 App 里。看着像，分工不同。选错了不仅低效，有些事根本做不了。

三模式速判

Chat 对话 Cowork 协作 Code 代码
长处 对话 / 写作 / 看 PDF / 头脑风暴 跨多源整合 / 跨 App 自动化 / 桌面端任务 直接读写你电脑文件、跑命令、用 Skill
适合用来 起草邮件、改文稿、分析报告 跨 Notion+表格+网页拉信息出成品 整理本地文件夹、Skill 触发、Excel/PDF 批量处理
能不能改你电脑文件 ❌ 不能 ⚠️ 受限 ✅ 能（所以需要护栏）
能不能装 / 用 Skill 部分 是 完整支持

怎么切换

侧边栏顶部三个图标：对话气泡（Chat） · 滑杆（Cowork） · 尖括号（Code）。点击切换。
快捷键 Ctrl + O 在三个模式间循环。

对话和上下文在三模式间连贯，可以随时切换不丢内容。

给你的默认判断

你在做什么 用哪个
起草邮件 / 写汇报 / 改文案 Chat
看一份 50 页 PDF / 报告 / 合同 Chat 起步，要保存产物再切 Code
让它跨 Notion + 邮件 + 表格做周报 Cowork
整理桌面文件 / 让它跑 Skill / 改本地文档 Code
行业扫描 / 简报 / 决策分析（任何 Skill 场景） Code
不确定 先 Chat，需要它动你电脑时再切 Code

一句话：Chat 是嘴，Cowork 是手，Code 是脚 —— 能踩到你硬盘的只有 Code。

3. 模型 + Plan Mode — Team plan 的两个杠杆

你是 Team plan 用户，账上有三个模型：

模型 适合 用法建议
Opus 复杂思考、战略分析、决策、长文档解读 默认用 Opus —— 你的时间宝贵，多花的额度换更高质量值
Sonnet 日常对话、起草、简单整理 量大、不重要的事用它，省 Opus 额度
Haiku 短问答、批量小任务 几乎用不上

切换模型

输入框右侧、发送键左边有一个模型切换按钮，点开切换 Opus / Sonnet / Haiku。整个对话期间保持，直到再次切换。

Plan Mode — 重要决策前先让它出方案

输入框左侧有一个 Plan Mode 切换按钮，点击循环三种状态：

  • Default — 它直接做
  • Plan Mode ★ — 它先出方案给你看，你点头才动手
  • Auto-accept — 它做完无需确认（仅小事用）

动你电脑文件 / 跑 Skill 的任务，强烈建议 Plan Mode。 看完方案再放行，避免误操作。

4. 5 分钟装好这套包

整个过程 2 步。你不需要手动复制粘贴文件，Claude 自己装。

步骤 1 · 让 Claude 装 Skill

把交付给你的 zip 解压到任意非 C 盘位置（推荐 D 盘）。例：D:\boss-claude-kit\。

打开 Claude Desktop → 切到 Code 模式 → 把下面这段话整段复制进去，按回车：

我有一个 Skill 包在 D:\boss-claude-kit\skills\（如果你解压到别的位置，把路径改成你解压的位置）。
请把里面的 10 个 Skill 文件夹复制到 ~/.claude/skills/。
完成后告诉我装了几个 Skill。
注意：不要在 C 盘留任何工作文件，所有工作产物默认放非 C 盘的工作盘。

Claude 会自动帮你拷贝，然后提示重启。完全退出 Claude Desktop 再打开。

步骤 2 · 让 Claude 配置安全护栏

重启后，切回 Code 模式，对它说：

「帮我配置安全护栏」

它会问你 5 个业务问题（用户名、要保护的目录、敏感关键词、严格度），3-5 分钟完成。你只需要回答业务相关的问题，技术细节它都帮你处理。

完成后再重启一次 Claude Desktop，护栏生效。

装完后 Claude 会自动按下一章的"装完之后你得到了什么"全部行为运行，不需要你手动验证。

5. 装完之后，你得到了什么

这是这套包的核心价值。装完后，你的 Claude Desktop 会自动具备以下行为，你不用再每次提醒它。

A. 安全护栏 — 它不会再做这些

  • 删你桌面、文档、OneDrive、合同、财务、客户名单任何目录里的文件
  • 跑 rm -rf / format / 批量删除 这一类毁灭性命令
  • 在你不点头的情况下：git push / 群发邮件 / Slack / 修改共享文档
  • 把含「合同 / 财务 / 客户 / 机密 / 董事会」关键词的文件上传外部
  • 同时删除 3 个以上文件而不问你
  • 写入 C:\Windows / Program Files 这类系统目录

B. 你可以放心做这些

  • 让它「整理一下我桌面」 — 它先告诉你怎么整，不会误删
  • 把合同、财务报表、客户名单 PDF 拖给它分析 — 内容不出本地
  • 让它跑命令、改文件、用 Skill — 每个动作前先用中文告诉你
  • 不确定的事情，它停下来问，不赌

C. 公司行为标准（已默认开启）

护栏配置同时帮你预设好了公司级工作习惯，你的 Claude 自动遵守：

默认行为 含义
不在 C 盘留工作文件 所有工作产物 / 交付物默认放你的工作盘（D 盘或其他非 C 盘）
重要操作先出方案 动文件 / 用 Skill 前进入 Plan Mode，等你点头
环境优先 开工前先确认工具版本 / 路径 / 依赖，不假设就动手
交付前实跑 生成的工具 / 脚本 / 文档必须验证可用，不只静态 review
失败两次即停 同一种方法连试两次失败，停下汇报，不换花样硬试
参考材料优先 你给的 PDF / 截图 = 主要参照，先读完再问
PDF 命名规范 按「主题-来源机构-版本」格式存（如 保险监管报告-银保监-2026Q1.pdf）

D. 一个隐形的双保险

护栏在两层同时工作 — 即使 Claude 内部判断失误，系统层会兜底拦截。你不需要懂它怎么实现的，它就是这样工作的。

想加新规则？

任何时候跟 Claude 说：
- 「再加一个保护目录：[路径]」
- 「以后含 [新关键词] 的文件也按敏感处理」
- 「放宽 / 收紧安全护栏」

它会自动改配置，你不需要打开任何文件。

6. 让 Claude 出好活的 4 个核心技巧

技巧 1 · 用业务语言描述场景，不要记 Skill 名

❌ "用 exec-briefing 给我做一份…"
✅ "下周给董事会汇报 [话题]，帮我准备一页纸简报。"

Skill 自动触发。场景说清楚，Claude 自己选对工具。记名字容易记错。

技巧 2 · 一开始就讲清「受众 + 决策点 + 时间」

维度 例
受众 董事会 / 投资人 / 监管 / 集团总部 / 业务合伙人 / 销售群发 / 自己看的笔记
决策点 需要他们批准 X / 我自己要决定 Y / 仅了解情况
时间敏感度 本周内 / 月底 / 长期议题

例：「我要给董事会汇报，需要他们批准下季度 5 个新城市拓展，周三例会前给他们。」

技巧 3 · 大任务拆小，分轮对话

❌ "帮我做一份 P3 关停的完整方案"
✅ ①评估该不该关（决策框架）→ ②准备董事会简报 → ③准备客户告知信

每轮聚焦一件事，输出才真正可用。

技巧 4 · 不满意直接回怼，不要重起炉灶

直接说：
- "这段太空了，给具体数字"
- "决策建议藏在末尾，挪到最前"
- "没考虑到 [Y]，重写"

它会针对反馈调整，比关掉重开省力 10 倍。

7. 你拥有的 10 个 Skill

正常对话自动触发，不需要记名字。

⓪ setup-guardrails — 安全护栏配置向导

用来： 给 Claude 装上安全护栏
怎么说： 「帮我配置安全护栏」

① exec-briefing — 一页纸高管简报

用来： BLUF（结论先行）把任何议题浓缩成 ≤ 1 页 ≤ 500 字
适合场景： 给董事会 / 投资人发汇报、会议 pre-read、决策备忘
怎么说： 「帮我准备一页纸简报，给 [谁] 看，需要他决定 [X]」

▎决策建议
建议 11 月底前关停 P3 产品（年亏 1200 万），团队转岗 P5。
▎为什么
1. P3 赔付率连续 3 季度 > 110%（行业 78%）
2. P5 件均保费 +22%，但产能闲置 40%
3. 转岗 8 人，无需对外招聘
▎风险
P3 现有 3,200 客户续保需提前 30 天合规告知
▎需要您
下周二例会前给 GO/NO-GO

② strategy-frameworks — 战略框架分析

用来： SWOT / Porter 五力 / MECE / 2x2 矩阵 / JTBD 拆解模糊商业问题
适合场景： 评估市场、竞品分析、把模糊战略问题拆清楚
特点： 不堆叠多框架 — 先选 1 个最适合的告诉你为什么，填完给 "So what"

③ decision-coach — 决策教练

用来： Pre-mortem / 二阶思考 / 期望值 / 反向思考帮你想清楚高风险决策
适合场景： 纠结要不要做 X、重大投入前、担心做完会后悔
特点： 先逼你扩选项（除了 A 和 B，还有 C/D 吗？），用 1 个工具深入分析，输出 Decision Memo 记录 + 定回看时间

④ industry-scan — 行业扫描

用来： 保险 / InsurTech / 健康险周月报，🔴🟡🟢 三色优先级
适合场景： 周/月度市场扫描、战略会前的市场背景、监管动向追踪

🔴 需关注 · 银保监 11/4 发文规范代理人销售
  → 我们需要 30 天内更新代理人内训
🟡 值得追踪 · 众安 Q3 健康险件均下滑 8%
🟢 行业背景 · 平安发布健康管理 App 2.0
🔭 接下来 30 天 · 11/15 国家医保局年度通报

⑤ one-on-one-prep — 1:1 谈话准备

用来： 准备和直接下属的 1:1，按"任务 30% / 关系 30% / 个人成长 40%"
适合场景： 定期 1:1 前 10 分钟、季度 check-in
特点： 避免 1:1 变成"项目状态汇报"，强制覆盖关系层 + 个人成长层 + 给敏感话题准备预案

⑥ feedback-mastery — SBI 反馈框架

用来： Situation-Behavior-Impact 框架给反馈（正面 + 负面）
适合场景： 给下属反馈、跨部门反馈、接受反馈时
特点： 把"我觉得你态度不好"这种评价型反馈，转成 "S+B+I" 可改进反馈

⑦ difficult-workplace-conversations — 困难对话准备

用来： 准备真正难聊的话题（裁员、降职、薪酬、绩效不达标）
适合场景： 涉及钱、地位、感情、担心谈崩
特点： 三阶段 + 各种情绪反应预案 + 清晰的可控 / 不可控边界

⑧ document-digest — 长文档三层摘要

用来： 长 PDF / 报告 / 合同读不完时给 30 秒 / 3 分钟 / 10 分钟三层摘要
适合场景： 50+ 页报告、合同审阅（会扫埋在末尾的坑）、监管文件、年报
怎么说： 直接把 PDF 拖进来说「给我个三层摘要」

⑨ skill-creator — 造你自己的 Skill

用来： 把你反复在做的工作流沉淀成 Skill
怎么说： 「帮我做一个 Skill：[你想要的功能]」 — 下一章详细教

8. 把常做的事沉淀成 Skill — 3 分钟入门

什么是 Skill

Skill = 一份给 Claude 的指令书，告诉它"遇到 [X 场景] 按 [Y 套路] 处理"。

类比：你雇新助理，第一天会给他一份「接电话标准流程」让他背。Skill 就是给 Claude 的标准流程。

一个具体例子：「费用报销审查助手」

痛点： 你每月底审同事提交的费用报销，每次问的都差不多。
Skill 化后： 同事把报销单丢进来，Claude 按你的清单审一遍，给你 ✅/⚠️ 报告，你 30 秒确认。

怎么做这个 Skill — 一句话

切到 Code 模式，说：

「用 skill-creator 帮我做一个 Skill：每次同事发我费用报销单（PDF 或表格），自动审 5 件事：①发票齐全；②单笔 ≤ 500 元；③不含烟酒；④出差日期匹配出差申请；⑤同一项目不重复报销。给我 ✅/⚠️ 报告。」

skill-creator 会问你触发条件、规则细节、输出格式，然后把 Skill 写好放进你的 Skill 目录。10-15 分钟搞定。

什么样的事值得 Skill 化

  • ✅ 每周 / 每月都做一遍 · ✅ 有固定步骤 / 规则 · ✅ 想让团队用同样标准做
  • ❌ 一次性的活 · ❌ 需要主观判断的事
