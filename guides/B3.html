再记住一件事：AI 很健忘

它没有记忆。你和它说的每句话、发给它的每个文件，都记在一个「工作本子」里。你每发一条消息，它都要把整个本子从头读一遍，才知道该干嘛——读的每一页都要花钱。所以本子越厚、越乱，每句话就越贵，它还越容易看花眼。今天的所有技巧，说白了就是：把对的活交给对的工具，再让本子保持薄而干净。

按任务查：点标签看细节

写周报、改稿、总结长文、整理会议纪要——这类日常文字活，占大家用量的大头。

用什么：Cherry Studio 就够。要动本地文件（一堆 Word 批量改）才开 Claude Code。
哪档模型：日常走量用 deepseek-v4-flash（又快又便宜）；要中文质感、给领导看的用 claude-sonnet-4-6；正式对外稿用 kimi-k2.6 或 qwen3-max 收尾。
  • 一次把要求说全：改哪里、改成什么样、口吻保持不变。
  • 让它参考现成的好稿子，别让它凭空自由发挥。
  • 换一个新任务，就开一个新对话（别在一个窗口里从周一聊到周五）。

翻文献、翻涉外文书、整批文件翻译——翻译是最典型的"量大、单件简单"的活。

哪档模型：直接上便宜档（deepseek-v4-flash、qwen-plus，都在 Cherry Studio 模型列表里）。这不是"将就"：国际翻译评测（WMT25）人工评分里，DeepSeek 便宜档排总榜第 4，已经超过 Google 翻译和 DeepL 这些专业翻译引擎。
关键：质量瓶颈在术语不在模型档位——先把中英术语表放进开头，数字、否定句、免责条款抽查。
  • 先拿 1 个文件试翻，看质量满不满意、大概花多少钱，再决定要不要整批放量。
  • 一个文件一个对话，别把几十个文件堆进同一个窗口（否则每翻一个，前面所有文件都被重读一遍，钱就这么烧的）。
  • 术语表 / 要求放在开头固定不动，能省钱。
  • 例外：对外合同、医疗术语、品牌级文案——旗舰档起草 + 人工审校，这类别交给便宜档。

做 PPT、一页纸、海报、营销物料——需要出"好看的东西"的活。

用什么：拆成两步——文字和版式让主力档（sonnet）出大纲、出页面；配图在 Cherry Studio 里用豆包生图（seedream），按张计费，两毛钱左右一张。
别这么干：让最贵的模型对着整份 PPT 反复"美化"——又贵又不对路（第④节细讲）。
  • 先出大纲、定结构，再逐页出内容——别让它整份重写。
  • 配图用生图模型按张买，别让语言模型"描述出"一张图。
  • 公司有品牌规范和插画包，做对外物料先套用，风格才统一。

汇总表格、清洗数据、对账、生成报表——运营和财务的高频活。

用什么：要处理本地 Excel / 一堆文件，用 Claude Code（VS Code 插件或 Desktop 都行，能直接读写你电脑里的文件）。一次性的小表格，Cherry Studio 里发上去也行。
哪档模型：主力档起步；每周都要跑的固定活，让它帮你做成一个小工具，之后一键复用。
  • 把文件的完整路径直接给它，别让它自己满电脑找。
  • 说清楚要什么结果（汇总哪一列、按什么分组），别只说"帮我处理一下"。
  • 重复三次以上的活，就值得固定成工具——做一次，以后近乎免费。

把一堆资料变成"能问答的知识库"——比如保险条款库、产品手册问答。

用什么：Cherry Studio 自带知识库功能，两个零件配合——Embedding 模型负责"找得准"（选 text-embedding-3-small，白菜价），主力档模型负责"答得好"。
最关键的一步：资料先清洗干净再入库。答得准不准，八成定在这一步。
  • 第一次用，要先在设置里添加一个 embedding 模型（管理员统一预配好，人人零门槛）。
  • 图片版 PDF、格式乱的文件，先转成干净文本再入库（文档里的图片不参与检索）。
  • Embedding 是"检索零件"，不是用来聊天的——别搞混。这类项目建议找懂的同事一起起步。
💡 拿不准某个活用什么？丢到 AI 群里问一句——大概率有同事已经趟过这条路。

③花多少钱，心里有个数

不用记价格表，记住两件事就够：模型分档，越难的活才用越贵的档。

💡 先分清你要不要操心成本。日常文字、查资料、小表格这类活，在 Cherry Studio 里选主力档轻量用，一天也就几毛到几块钱，成本基本可以忽略。真正要盯成本的是"用量大户"：整批翻译、大数据清洗、自动化、长文档反复处理。下面这些，主要写给这类活。

先建立一个体感

AI 按"字数"收费（术语叫 token，1 个汉字约合 1 个 token 上下）。一个直观的参照：让旗舰模型读完约 700 页 A4 文档，大概 ¥30。单看不贵——真正烧钱的是两件事：让最贵的模型干便宜活，和让它把没用的内容反复重读。

模型就三档，按活的难度选（都在集团网关里，Cherry Studio 直接切）

便宜档 · 跑量

deepseek-v4-flash · qwen-plus · 豆包 seed-1-6-lite · qwen3-vl-flash（读图）

翻译、格式转换、批量摘要、打标、扫描件。量大、单件简单的活全用它，比旗舰便宜几十倍。

主力档 · 日常

claude-sonnet-4-6 · gpt-5.4 · kimi-k2.5 · gemini-3.5-flash

写文书、整理报表、改稿、读长 PDF。日常绝大多数活的主力，够快够好。

旗舰档 · 硬活

claude-opus-4-8 · gpt-5.5 · kimi-k2.6 · deepseek-v4-pro

复杂方案、深度分析、重要对外文稿。一天也就几件，好钢用在刀刃上。

📌 中文写作的"气质分工"（社区共识）：Qwen 最规范→正式文书；Kimi 有文采→品宣对外稿；豆包懂热点→新媒体短文案；DeepSeek 逻辑强→技术文档和走量初稿。中文的活优先国产模型——便宜，中文还算得省。

一个经过验证的用法：先跑通，再放量

复杂或大批量的活，分两步：先用旗舰档把流程跑通——定好指令模板、输出格式、质检标准；跑通后换便宜档批量执行。这不是土办法，是 OpenAI 和 Anthropic 官方文档都推荐的标准工作流（OpenAI 官方案例：同一个任务这么做，成本降约 57 倍、精度不掉）。

✅ 适合：模板化程度高、输出检查得了的活——分类、抽取、格式转换、批量翻译。
❌ 不适合：每一件都要深度判断的活，该用旗舰就用旗舰。
⚠️ 一个坑：切到便宜档后先抽查几份再全量——小模型出错是"悄悄变差"，不抽查看不出来。
⚠️ 选型号认准"最新版本号"——网关里的老型号有两种坑。
坑一 · 价格陷阱：新旧型号并排挂着，价钱天差地别——gpt-4（老）¥204/¥408，比新一代 gpt-5.4（¥17/¥102）贵 10 倍以上；claude-opus-4-1（老）比 opus-4-8 贵 3 倍。选错一个字，账单翻几十倍。
坑二 · 僵尸型号（官方已停维护/关停，别再用）：deepseek-r1（过时且幻觉高）、kimi-k2 / k2-thinking（已停更，用 k2.6）、qwen-max（两年前的老底子，比 qwen3-max 贵还弱）、gemini-3-pro-preview（官方已关停的死 ID）；gpt-5.1 / o3 / o4-mini 都在退役倒计时，别建新流程。

④两个最常见的误区

这两个坑几乎都发生在"量大"的活上——也就是上面说的"用量大户"。换个开法，就能省一大截。

一句话看懂

钱，基本都烧在这两件事上

✗ 让最贵的模型干便宜活

翻译、美化这类活，便宜档就干得很好；用旗舰档，价钱翻几十倍，效果差不多。

✗ 让它把没用的内容反复重读

几十个文件挤在一个对话里，每问一次，全部内容都被从头读一遍——本子越厚，每句话越贵。

同样的翻译量：换对模型 + 分开处理，从几百块 → 一块多。

误区一 · 把 PPT 丢进写代码的工具，让最贵的模型反复"美化"

❌ 容易踩的开法✅ 正确的开法
用最贵的旗舰模型，对着整份 PPT 反复"再美化一下"，每改一次全文重写一遍——一个下午几百块。拆开干：版式和文字让主力档（sonnet）只改样式、只出改动的那几页，别整份重写；配图用豆包生图按张计费（约两毛一张）。同样的效果，价钱差一个量级。

Then, one thing to remember: AI forgets

It keeps no memory of past chats, and it only works with what is in the current chat and the files you attach. Picture that as one "notebook." Every message and file you add goes into the notebook, and each time you send something the model works through the notebook again to answer, so every page in it adds to the cost. The thicker and messier the notebook, the more each message costs, and the easier it is for the model to lose track. Every technique today comes down to this: give the right job to the right tool, and keep the notebook thin and clean.

Weekly reports, edits, long summaries, meeting notes. This everyday text work is the bulk of what people use AI for.

What to use: Cherry Studio is enough. Open Claude Code only when you need to touch local files, such as editing a batch of Word docs.
Which tier: everyday volume on deepseek-v4-flash (fast and cheap); Chinese polish for leadership on claude-sonnet-4-6; formal outward-facing drafts finished on kimi-k2.6 or qwen3-max.
  • Say the whole request at once: what to change, how, and keep the tone the same.
  • Give it a good draft to follow. Don't let it invent freely.
  • New task, new chat. Don't run one window from Monday to Friday.

Papers, foreign-language documents, whole batches of files. Translation is the classic high-volume, low-difficulty job.

Which tier: go straight to the low-cost tier (deepseek-v4-flash, qwen-plus, both in the Cherry Studio model list). This is not settling: in the WMT25 human evaluation, DeepSeek's budget model ranked 4th overall, ahead of Google Translate and DeepL.
Key: quality lives in the terminology, not the model tier — put a bilingual glossary at the top, and spot-check numbers, negations, and exclusion clauses.
  • Test-translate one file first. Check the quality and the rough cost before you run the whole batch.
  • One file, one chat. Don't pile dozens of files into a single window, or every earlier file gets reread each time you translate the next one. That is how the money burns.
  • Keep the glossary and instructions at the top, unchanged. That saves money.
  • Exception: outward-facing contracts, medical terminology, brand-level copy — draft on the flagship tier with human review. Don't hand these to the low-cost tier.

Slides, one-pagers, posters, marketing material. Work where the output has to look good.

What to use: split it in two. Text and layout: have the workhorse tier (sonnet) draft the outline and the pages. Images: use Doubao image generation (seedream) in Cherry Studio, billed per image at roughly ¥0.2 each.
Don't do this: have the priciest model "polish" a whole deck again and again. It costs a lot and it is wrong for the job (section ④ has the detail).
  • Outline first, then pages one by one. Never let it rewrite the whole deck.
  • Buy images per picture from an image model. Don't make a language model "describe" one into existence.
  • The company has brand guidelines and an illustration pack. Use them for outward-facing material so the style stays consistent.

Summarizing tables, cleaning data, reconciling accounts, building reports. High-frequency work for operations and finance.

What to use: for local Excel or a batch of files, use Claude Code (VS Code extension or Desktop, either reads and writes files on your computer directly). For a one-off small table, pasting it into Cherry Studio is fine.
Which tier: start with the workhorse tier; for a fixed job you run every week, have it build you a small tool, then reuse it in one click.
  • Give it the full file path directly. Don't make it hunt around your computer.
  • Say what result you want (which column to sum, how to group). Don't just say "help me sort this out."
  • Any job you repeat more than three times is worth turning into a tool. Build it once, then it is nearly free.

Turning a pile of documents into a knowledge base you can ask questions of, such as a policy-terms library or a product-manual Q&A.

What to use: Cherry Studio has a built-in knowledge-base feature. Two parts work together: an embedding model handles "find the right passage" (pick text-embedding-3-small, dirt cheap); a workhorse model handles "answer well."
The step that matters most: clean the documents before you load them. Roughly eight in ten of your answer quality is decided here.
  • First time: add an embedding model in settings once (if the admin pre-configures it, it is zero-setup for everyone).
  • Scanned PDFs and messy files: convert them to clean text before loading (images inside documents are not searchable).
  • Embedding is the retrieval part, not a chat model. Don't mix the two up. Start this kind of project with a colleague who knows it.

③Know roughly what it costs

You don't need to memorize a price list. Two things are enough: models come in tiers, and only harder work needs a pricier tier.

💡 First, work out whether you even need to worry about cost. Everyday text, research, small tables, run lightly on a workhorse model in Cherry Studio: a few jiao to a few yuan a day, use it freely. The ones who really need to watch cost are the "heavy users": bulk translation, big data cleaning, automation, long documents processed over and over. What follows is mainly for that kind of work.

Build a feel for it first

AI charges by text volume (the term is token: one English word is about 1.3 tokens, one Chinese character about 0.6 to 2 depending on the model). A simple reference: having a flagship model read about 700 pages of A4 costs roughly US$4.4 (about ¥30). On its own that is not much. The real money goes to two things: making the priciest model do cheap work, and making it reread useless content over and over.

Just three tiers, chosen by difficulty (all in the group gateway, switch in Cherry Studio)

Low-cost · volume

deepseek-v4-flash · qwen-plus · Doubao seed-1-6-lite · qwen3-vl-flash (vision)

Translation, format conversion, batch summaries, tagging, scanned docs. Anything high-volume and simple. Tens of times cheaper than a flagship.

Workhorse · daily

claude-sonnet-4-6 · gpt-5.4 · kimi-k2.5 · gemini-3.5-flash

Writing documents, tidying reports, editing, reading long PDFs. The workhorse for most daily work. Fast and good.

Flagship · hard jobs

claude-opus-4-8 · gpt-5.5 · kimi-k2.6 · deepseek-v4-pro

Complex plans, deep analysis, important outward-facing writing. A few a day at most. Use it only when the job genuinely needs it.

📌 Chinese writing "personalities" (community consensus): Qwen is the most formal → official documents; Kimi has flair → outward-facing and brand copy; Doubao knows the internet → social-media snippets; DeepSeek is logical → technical docs and volume drafts. For Chinese-language work, prefer the Chinese models — cheaper, and they count Chinese more efficiently.

A proven way to work: pilot first, then scale

For complex or high-volume work, take two steps: first get the workflow right on a flagship model — fix the prompt template, the output format, and the quality checks; then switch to a low-cost model for the volume run. This is not a folk trick: OpenAI's and Anthropic's official docs both recommend exactly this workflow (OpenAI's own case study: the same task done this way cost about 57 times less with no loss of accuracy).

✅ Fits: highly templated work whose output you can check — classification, extraction, format conversion, batch translation.
❌ Doesn't fit: work where every item needs deep judgment; that stays on the flagship.
⚠️ One trap: after switching down, spot-check a few outputs before the full run — small models fail quietly, and you won't see it without sampling.
⚠️ Pick the newest version number — old models on the gateway hide two traps.
Trap 1 · Price: old and new hang side by side at wildly different prices — gpt-4 (old) is ¥204/¥408, over 10 times the newer gpt-5.4 (¥17/¥102); claude-opus-4-1 (old) costs three times opus-4-8. One wrong pick multiplies the bill.
Trap 2 · Zombies (officially discontinued — don't use): deepseek-r1 (outdated, hallucination-prone), kimi-k2 / k2-thinking (unmaintained, use k2.6), qwen-max (a two-year-old base, weaker yet pricier than qwen3-max), gemini-3-pro-preview (a dead ID, officially shut down); gpt-5.1 / o3 / o4-mini are all on retirement countdowns — build nothing new on them.

④The two most common mistakes

Both traps happen almost entirely on high-volume work, the "heavy user" work above. A different approach saves a big chunk.

In one line

This is where the money goes

✗ Making the priciest model do cheap work

Translation and polishing run fine on the low-cost tier. On a flagship the price multiplies by tens of times for about the same result.

✗ Making it reread useless content over and over

Dozens of files crammed into one chat. Every question rereads all of it. The thicker the notebook, the more each message costs.

Same translation volume, right model and separate chats: from a few hundred RMB down to about ¥1. That is roughly 64 times cheaper.

Mistake 1 · Dropping slides into a coding tool and having the priciest model "polish" over and over

❌ The easy wrong way✅ The right way
Use the priciest flagship, tell it to "polish this some more" across a whole deck, and rewrite the full text each pass. A few hundred RMB in one afternoon.Split the job: have the workhorse tier (sonnet) change only the styling and only the pages that changed, never rewrite the whole deck; buy images from Doubao image gen per picture (about ¥0.2 each). Same result, an order of magnitude cheaper.

Mistake 2 · Dumping a pile of files in at once and translating them one by one on the priciest model

❌ The easy wrong way✅ The right way
Dozens of files in one chat, translated one at a time on a flagship. Each translation rereads every earlier file, so the cost compounds.Test one file on the low-cost tier first and check the quality. Once happy, one file per chat, or have Claude Code write a script to run through them automatically.
Decide where to run it and which tier, test a small sample, then scale. Three steps, in that order.
