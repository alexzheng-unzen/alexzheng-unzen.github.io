团队资产库 · Team Asset Library

我们沉淀好东西的地方

你跑通的好流程、好 prompt、好模板,不该只活在你一个人的电脑里。 放进来,它就能被别人找到、被反复用,还替你署着名。 这页讲清:库里有什么、什么算资产、怎么提交。

什么算一个"资产"

不用很大很正式。下面任意一类,只要别人能复用,就值得进库:

Skill

把整套流程打包,别人一句话就能调起来。

例:保单 PDF 清洗、RAG 检索增强包
模板 Template

留出空让人填,换个场景照样能用。

例:Excel 模板映射、课件 HTML 模板
Prompt

一段反复好用的话,存下来直接抄。

例:给同事工具时的"白盒化"指令开头
规则 Rule

写进 CLAUDE.md,让大家默认遵守。

例:Agent Clutter Prevention、品牌语气

怎么提交

不用写得很完整。复制下面这张小卡,填好,连同你的东西一起丢进库里就行。

资产提交卡 
【资产名】 一句话能看懂的名字
【类型】   Skill / 模板 / Prompt / 规则(选一个)
【解决什么】 它帮人省了什么事 / 解决什么问题
【怎么用】 一句话说清怎么调起来(命令 / 在哪填)
【作者】   你的名字
【日期】   YYYY-MM-DD
门槛很低:哪怕只是一段你反复在用的 prompt,也欢迎丢进来。 资产不是"做得多完美才配进库",而是"只要别人能用上,就值得留下"。
放在哪(待定):团队共享落点正在确认中—— 待定为飞书知识库或共享盘其一。确定后这里会更新具体入口, 本页也会作为它的封面/导航。在此之前,先把你的资产提交卡 + 文件发给 Alex 汇总。
