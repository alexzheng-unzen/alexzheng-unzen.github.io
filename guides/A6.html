用 AI 做设计,到底怎么真正落地?

这份指南只讲一件事:已经跑通的团队,到底把 AI 放在了哪一段。基于公开案例 + 独立实测,不是又一份趋势 PPT。每条都具名、带出处、标可信度,厂商自报的数字单独标注,并特意保留了反向证据。

一屏看懂:6 条不随版本失效的判断

模型每几个月换一代,但下面这 6 条决定「怎么学、怎么带团队、怎么用」的判断,穿越所有版本。

① 别再"炼咒语",要学"对话式指挥"

前沿模型(GPT Image、Nano Banana、Flux.2)吃自然语言。SD1.5 时代那套超长负面提示词、权重微调、ComfyUI 节点图,对 2026 起步的人 投入产出比极低,不必先学。

② 护城河是"眼睛"和"方向"

制作趋近免费,值钱的变成 art direction(定方向)+ 策展(会筛)+ 迭代节奏。有个真实张力值得知道:主流说"品味是唯一护城河",强反方说品味只是 alpha 不是 moat(默认水平每几个月被重置)。

③ 提效是真的,但只在"窄环节 + 人把关"

本指南最重要的一条。别家真正跑通的,都是把 AI 放进「已经很清楚该怎么做的那一段」;前面的判断和后面的把关仍是人。全自动 / 替代人 = 翻车高发区。

④ 核心方法 = 资产 / 版式分离

AI 产 PNG 内,设计工具管 PNG 外。AI 只生成素材(插画/照片/纹理),文字、版式、间距、token 留在 Figma——文字是真文字层,永不被缩。见 §4。

⑤ 有结构或数字的,绝不生成扁平图

凡是有结构(UI)或有数字(图表/仪表盘)的东西,生成矢量图层或代码(React/HTML/SVG)。就算出图模型文字清晰度上来了,它仍是扁平像素:字会缩、没法编辑、比例靠眼估。

⑥ 押可迁移的判断力,别押具体工具

半年换一代(Nano Banana → Pro → 2)。把注押在"看得出好坏 + 说得清要什么 + 脑子里有风格词典"上,而不是某个 app 的操作。

⚠️ 关于时效:本文凡涉及版本号、价格、发布日期,约 30% 来自二手源(厂商官网常是 JS 渲染 / 403 抓不到)。做采购决策前,请对官方 /pricing 页当日复核一次。各条已标可信度,详见 §10 诚实边界。

SECTION 01 / LANDSCAPE

①趋势:现在在发生什么 / 别学什么 / 大家在追什么

技术日新月异,这一节把"仍在主线上的"和"已经被淘汰的"分开,别把时间投在会过期的技能上。

主线范式:6 个正在发生的转变

1. 从"炼提示词"→"对话式编辑"
图像生成已内嵌进语言模型(原生多模态)。用大白话来回改("背景换成傍晚、她再笑一点"),而不是堆咒语。转折点:2025-03 GPT-4o 原生出图。· 高可信
2. 图像模型开始"先想后画"
2026-04 OpenAI gpt-image-2 号称首个"画前先推理":先规划构图、检查空间关系、校验文字,含 Thinking 模式。把 LLM 的 reasoning 带进出图。· 中高
3. 一致性(consistency)成刚需
角色/风格/人脸跨多图保持一致。Nano Banana Pro(2025-11)可融合 14 张参考图、保持 5 个人物一致、图内渲染清晰多语言文字。以前要训 LoRA,现在开箱即用。· 高
4. 可控多图工作流 > 单图抽卡
关注点从"抽一张好图"转向"可控批量产出成套素材"(同角色多场景、多分镜、多尺寸)。面向漫画、故事板、品牌套图。· 高
5. 实时生成(realtime)上台面
Krea 的 Realtime Canvas 边画边出图,涂个草稿它实时补成成品。设计从"提交—等待—评审"变成"实时捏"。· 中
6. 世界模型 / 3D / 视频"世界化"
生成从平面扩到可交互 3D 世界(DeepMind Genie 3、World Labs Marble)。视频侧原生带声(Veo 3.1)、原生 4K 多镜头(Kling 3.0)、Sora 2 已成常规。· 中高

🚫 已过时 / 别浪费时间

  • SD1.5 "咒语学" —— 超长负面提示词、booru 标签堆砌、(keyword:1.4) 权重微调,是为绕开老模型的崩坏。前沿模型基本不吃。
  • 一上来钻 ComfyUI / ControlNet 节点图 —— 技术仍有效,但"管工具链比出图还费时"。除非做本地化/隐私/大批量微调,否则别先学。
  • 迷信"负面提示词万能"和固定咒语模板 —— SDXL 起就对负面词不敏感,抄"魔法提示词大全"边际价值在衰减。
  • 把某个单一 app/模型当成要 all-in 学的东西 —— 半年换一代。押注可迁移的判断力,别押注具体工具。

🔥 2026 大家在追什么

  • 推理型出图(reasoning / "thinking" image gen)
  • 世界模型(Genie 3、NVIDIA Cosmos、World Labs Marble)—— 会不会盖过纯 LLM 是热议
  • 原生多模态统一模型(底层 MMDiT,把图像块当"词")
  • 节点式 / agentic 创意工作流(Freepik Spaces、ComfyAgent —— 用 AI 帮你搭工作流)
  • "taste is the moat"大讨论 —— 品味到底是护城河还是只是暂时领先,这个张力值得持续关注。
真正拉开差距的能力:艺术指导(定义"为什么"和情绪)、策展与筛选(知道留什么砍什么)、迭代节奏(用对话式/实时工具快速收敛)、系统化(把一致性、品牌 token、成套素材做成可复用工作流)。制作层被自动化后,这四件事才是价值所在。

SECTION 03 / THE METHOD

③核心方法:资产 / 版式分离

最常见的坑:拿 ChatGPT / 出图模型做精确 UI,每次都把字号缩小、版式重排——这不是 prompt 写得不够狠,是工具选错了层。

💡 知识卡 · 为什么出图模型的「文字」总在漂移?
扩散/像素模型每次生成都在重新采样整张图,所谓「文字」只是一片像素,不是文字层。所以字号、字形、措辞每一版都会变。就算 Nano Banana Pro 的文字渲染是业界最好的,那也是烤进图里的像素——做海报可以,做「要能改的 UI 文案」就是用错了。8px 网格、精确 hex、固定字阶,这些是结构属性,扩散模型根本不具备,再硬的 prompt 也约束不出来。

✗ 旧打法:让 AI 出整屏 UI

  • 文字被当图像重绘 → 字号缩小、措辞乱变
  • 版式每次重排,改一个字要重生成整屏
  • 输出是扁平像素:无图层、无组件、无层级
  • 换肤/本地化/改文案 = 从头再来
  • 越写越硬的 prompt,治标不治本

✓ 新打法:资产 / 版式分离

  • AI 只生产「PNG 里的东西」(插画/照片/纹理/去背素材)
  • 设计工具拥有「PNG 以外的一切」:位置/尺寸/文字/间距/token
  • 文字是真文字层,永不被缩——因为这条回路里没有模型
  • 改文案 = 直接改文字层;换肤 = 换 Variables
  • 需要一致的一组图 → 对素材「局部改」,不整屏重生成

SOP:一条能照着做的流水线

以「一组 App onboarding 插画放进卡片」为例,逐步走。AI = 交给模型;人 = 在 Figma 里做。

  1. 人 · Figma — 先定约束。确认插画配色/圆角/卡片规格已经是 Variables(品牌主色等存为 token);备好 2–3 张品牌参考图 + logo + 色板图 = 一个 reference kit。
  2. AI · 生成模型 — 生成原始插画。喂 Reference Stack,只描述插画本身(主体/风格/配色/透明或纯底)——不要 UI、不要卡片、不要按钮、不要文字标签;要 2K 以上。
  3. AI · 同模型局部改 — 做成一致的一组。要成套(如 3 屏)时,用「局部/增量改图」("同一角色同风格,现在拿着手机"),别从头重 prompt——这才锁得住跨图一致性。
  4. 人 · Figma/PS — 清理素材。去背/压平 → 透明 PNG;需要就升分辨率;统一丢到一个 Assets 页,别污染排版文件。
  5. 人 · Figma(核心步骤) — 在画布搭真版式。卡片 = auto-layout 帧绑 Variables(圆角/内距/填充);PNG 作为图层放进去;每一句文案都是真文字层、用库里的字体样式。文字在这里永不被缩,因为没有模型碰它。
  6. AI · 局部 — 只微调,不动像素。插画要改色/光/裁切 → 只把素材送回模型做局部改 → 重导 → 换掉填充;版式、文字、间距一律不动。
  7. 人 · 可选 — 要可点 demo 才用 Figma Make 生成代码版,或走 Dev Mode 带 token 交付。放在成品下游,别在里面做设计(它出的是代码,不是可编辑图层)。
  8. 人 — 一致性检查。整组丢进 3×3 平铺,签字前肉眼过一遍配色 + 插画协调。

🎯 黄金律:AI 在 PNG 里生产,设计工具管 PNG 以外的位置 / 尺寸 / 文字 / 间距 / token。任何时候拿不准,回到这一句。

三个上手实验(验证这套方法,过关标准是二值的)

不求一步到位,跑通一个就是真进展。过关标准都设计成「能 / 不能」,没有模糊地带。

  1. 实验 A · 一致插画组进卡片。用生成模型做 3 张同风格插画 → 放进 Figma auto-layout 卡片,配真文字层。✅ 过关:拿给一个没参与的人看,他一眼认得出这 3 张是「同一套」。
  2. 实验 B · 免费出 onboarding 首屏。用 Google Stitch prompt 一版移动首屏 → Paste to Figma → 手工改上品牌色。✅ 过关:落回 Figma 的是真图层不是图,且能直接点开改文字。
  3. 实验 C · 真数据仪表盘环。用 GaugeGarage 出可编辑矢量环,或让 v0 出 Recharts RadialBarChart 代码版。✅ 过关:环的扫过角度对应真实数值,不是眼睛估的。
💡 那种"数据仪表盘的进度环 / 仪表盘环"怎么办? 诚实结论:2026 年没有「AI 直接生成数据准确的环形图」。两条真路——(1) 在 Figma 里用 GaugeGarage 插件画可编辑矢量环;(2) 让 v0 / Claude 出 Recharts 的 RadialBarChart 代码(真数据绑定,环的扫过角度对应真实数值)。别用出图模型糊一个,那是眼估的、改不动的。S16

SECTION 05 / RIGHTS & SAFETY

⑤版权与商用安全——尤其对外发资产的品牌

对外发布资产的品牌(尤其金融、保险、医疗等合规敏感行业),不能用「有版权污点」的输出。这块单独拎出来说清楚。

⭐ 商用最稳 = Adobe Firefly
只用授权 Adobe Stock + 公有领域 + 开放授权内容训练;付费 CC 计划含 IP 赔付(有人告你侵权,Adobe 出面抗诉),企业版赔付上限更高。(小瑕疵:Firefly 现在也部分训练自 Adobe Stock 上的 AI 图,"纯净"叙事有杂质)
⚠️ Midjourney = 慎用于对外
训练数据爬全网 → 有诉讼风险;付费可商用、你拥有输出,但零 IP 赔付、公司明确免责;无企业版/SSO/API(截至 2026-04)。→ 只做灵感,别做对外终稿。
Recraft / Ideogram
付费计划给完整商用权。Recraft 免费带水印且禁商用;Ideogram 免费即可商用无水印。
Nano Banana Pro (Gemini)
付费可商用,输出带 SynthID 隐形水印。做一致性插画的主力,但对外合规敏感件仍优先 Firefly。
🔴 法律灰区 + 采购红线:纯 AI 生成物在美国可能不受版权保护(美版权局立场)→ 品牌资产一定要保持人类作者在回路(「资产/版式分离」天然满足:人做版式和最终编排)。采购/上线前务必核对各家 2026 官方 ToS,价格全部现场复核。
🎯 推荐默认栈:对外正式/合规敏感 → Firefly;内部/灵感/一致性插画 → Nano Banana Pro;品牌矢量/图标/设计系统 → Recraft;带文字的图/logo → Ideogram;UI 结构 → Magic Patterns / Stitch。

SECTION 08 / DON'TS

⑧别踩的坑(贴墙上那种)

别让任何出图模型输出成品 UI——全是无结构像素,没有真文字层/组件/层级。
别指望文字留住——每次重绘都漂移或糊,再好的文字也只是烤进图里的像素。
别靠重 prompt 整屏来迭代——会重排版式;只对素材做局部改。
别想 prompt 约束出 8px 网格/精确 hex/固定字阶——那是结构属性,模型不具备。
别把插画连卡片/按钮/文字一起生成——之后没法换文案、换肤、本地化。
别把 Figma Make 当排版工具——它出代码,重 prompt 一样会重排。
别跳过设计系统绑定——不绑 Variables/auto-layout,就丢了这套流程唯一的价值。
别拿 Midjourney 这类无 IP 赔付的输出直接上对外正式物料。
