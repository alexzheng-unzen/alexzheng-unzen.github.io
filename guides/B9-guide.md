# 拆零件 · 傻瓜指南

> 你不用把整个项目交出去。只要从你干的活里,**拆下能给别人用的小零件**,
> 让 AI 帮你写出来,再发成"同事的 AI 直接能用"的东西。
> 全程让 AI 替你做,你只负责认零件 + 复制粘贴。一次 5~10 分钟。

---

## 第 1 步 · 认出你的零件(做完一段活,问 3 句)

不用刻意找。每做完一段,顺手问自己这三句,中一个就有零件:

| 问自己 | 中了就是 |
|---|---|
| 这个做法,换个场景 / 换个人**还能用**吗? | **零件① 通用手法** |
| 我刚踩的这个坑,**想喊同事"别踩"**吗? | **零件② 踩坑警告** |
| 这件事,是不是**该有个全团队统一的做法**? | **零件③ 待定流程** |

> 💡 一个人独做的项目照样有零件——零件藏在"做法、坑、流程"里,不在"业务内容"里。

---

## 第 2 步 · 让 AI 替你写出来(复制对应那句话)

打开 Claude Code,把相关对话 / 文件拖进去,**按零件类型复制下面的话**发给它:

### ▸ 零件① 通用手法 → 打包成 Skill 或 Prompt

```
我反复用下面这套做法,帮我整理成可复用的东西:
① 如果是一套固定流程 → 打包成一个 Claude Code skill(起个一看就懂的名字、
   写清解决什么问题/何时用、把步骤固化、给个用法示例);
② 如果只是一段好用的话 → 整理成一段干净的 prompt,标出哪里要按情况替换(用【】框)。
做完告诉我怎么用、怎么发给同事让他也能用。
```

### ▸ 零件② 踩坑警告 → 写成一条规则

```
把下面这个坑,写成一条简短的团队规则,要能直接贴进 CLAUDE.md:
说清楚"别这样做 / 要这样做"+ 一句"为什么"。越短越好,一两句最佳。
```

### ▸ 零件③ 待定流程 → 写成一页"提案 + 草案"

```
我觉得这件事团队该有个统一做法。帮我写一页东西:
① 一句话说清现在没统一带来的问题;
② 我建议的统一做法(分步骤);
③ 留一个"待团队拍板"的位置。
语气是"抛出来一起定",不是"我说了算"。
```

> 💡 不满意?直接说"再短点 / 名字换一个 / 例子换成 XX 场景",来回两句就顺。

---

## 第 3 步 · 规范一下(让它能被复用)

花 1 分钟确认零件"长得规整、别人能直接拿":

- **Skill**:有没有名字 + 一句"干嘛用的" + 用法示例?自己按示例调一次,跑得起来吗?
- **规则**:是不是一两句话、一个新人也看得懂?
- **Prompt / 提案**:该替换的地方有没有用【】标出来?

> 跑不通就把报错 / 截图丢回给 AI,说"这里不对,你改",别自己 debug。

---

## 第 4 步 · 发成"同事的 AI 直接能用"(关键 · Agent-to-Agent)

这一步是重点。你发的**不是一篇要同事读完再照做的文档**,而是他的 AI 直接能吃进去的东西:

| 你的零件 | 怎么发 | 同事那边怎么用 |
|---|---|---|
| **Skill** | 把整个 skill 文件夹发给他 | 丢进他的 `skills` 目录,他一句话就能调起来 |
| **规则** | 把那一两句规则发给他 | 贴进他的 `CLAUDE.md`,他的 Claude 从此自动遵守 |
| **Prompt** | 直接把那段话发给他 | 他粘上就用 |

**配一句话一起发**(让他的 AI 自己装好):

```
这是我整理的一个【skill / 规则 / prompt】,解决【XX 问题】。
帮我装到合适的位置(skill 放进 skills 目录 / 规则写进 CLAUDE.md),
装好后告诉我以后怎么调用。
```

> 🎯 效果:同事甚至不用读懂细节——他的 AI 就长出了你的这点本事。这就是"分享能力,不只是分享知识"。

---

## 第 5 步 · 顺手入库(让它不丢)

把零件 + 一张小卡,放进团队资产库(落点未定时先发给 Alex 汇总):

```
【零件名】 一看就懂的名字
【类型】   Skill / 模板 / Prompt / 规则
【解决什么】 帮人省了什么 / 避了什么坑 / 统一了什么
【怎么用】 一句话(命令 / 贴哪 / 怎么调)
【作者】   你的名字
【日期】   YYYY-MM-DD
```

---

## 常见纠结(读这段就不慌)

**Q:我项目就我一个人做,真有得分享吗?**
有。分享的不是项目,是里面的零件——通用做法、踩过的坑、该统一的流程。这三样,独做的人一样攒了一堆。

**Q:零件太小了,值得发吗?**
值得。哪怕只是一句"别踩这个坑"。对收到的人,他的 AI 少翻一次车,就够本了。

**Q:我不会写代码,能做 skill 吗?**
能。你不写,第 2 步那句话发给 AI,它替你打包。你只要会说"这事是怎么做的"。

**Q:涉密的能发吗?**
❌ 不能。客户名单、内部财务、个人隐私不进库。**分享"做事的方法",不分享"敏感的数据"。**
