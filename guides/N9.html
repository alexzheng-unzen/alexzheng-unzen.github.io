训练一个「像你一样写」的 AI 写手

不是教 AI 重新学中文，而是给它一份你的写作说明书 + 一摞你的范文，让它照着模仿你。这份教程讲三件事：原理、要喂什么、怎么一点点调到像。

全程大白话ChatGPT & Claude 都讲费解处都配例子有可直接抄的模板
读完你会拿到
  • 搞懂一件事：所谓「训练」，其实是写说明书 + 给范文 + 反复改稿，不是真去训模型
  • 一张「喂什么」清单——五样东西，每样配填空模板，照着填就行
  • 两个平台的搭建步骤——ChatGPT 建 GPT、Claude 建 Project，截图级的点哪里
  • 一套调试方法——怎么看「像不像你」、怎么纠它、怎么把改稿经验沉淀下来
  • 一份「AI 味」黑名单——一眼认出机器腔，并改掉

说在前面：这只是目前比较顺手的一种做法，不是唯一标准答案。你可以先照着走一遍，再按自己的习惯改。下面凡是出现 橙色字 的地方，都是要换成你自己内容的「填空位」。

⓪先说清楚：「训练」到底在干嘛

很多人一听「训练 AI」就觉得要懂技术、要花钱、要写代码。其实你要做的事，更像是带一个新来的文案实习生。

🧑‍🏫 一句话类比 新人入职第一天，你会做三件事：① 给 ta 看几篇你过往满意的稿子；② 告诉 ta「我们部门写东西的规矩」；③ ta 写完你帮 ta 改，改几次就上道了。训练 AI 写手，做的就是这三件一模一样的事——只不过对象从实习生换成了 AI。

先破除三个误会

你可能以为实际上
要"训练模型"，得懂技术 / 写代码不用。你只是在聊天框里贴文字、传文件，全程打字就行
要花很多钱 / 很久不用。用现成的 ChatGPT 或 Claude，第一版半小时就能搭出来
搭一次就永久"学会"了它不会自动记住。你要把规矩写下来存好，每次让它写之前"喂"给它（下面会讲怎么一劳永逸）
你不是在教 AI 写作，而是在教它「写作时先变成你」。

①原理：AI 为什么能写得像你

AI 本来就会写中文，写得还挺溜——问题是它默认谁都不像，写出来是一种"谁都能用、所以谁都不像"的播音腔。要让它像你，靠三个杠杆。

杠杆 1
给范文

给它几篇你写的真稿子。它会从里面"扒"出你的句子长短、节奏、用词习惯，照着模仿。
👉 类比：给实习生看你的旧稿

杠杆 2
写说明书

用一段文字把"你是怎么写的"讲清楚：语气、爱用什么、绝不用什么。
👉 类比：部门的文案规范

杠杆 3
反复纠偏

它写完你改，告诉它哪里不对、应该像哪篇。改几轮就越来越准。
👉 类比：带新人改稿

费解点：为什么"给3篇范文"比"我说我风格活泼"更管用？

这是最反直觉、也最关键的一点。光用形容词描述自己的风格，AI 会自己脑补，而它脑补出来的"活泼"往往是网红爆款腔，不是你的活泼。范文是证据，形容词是猜测。看个对比：

✕ 只给形容词

指令：「帮我写条护肤品小红书，风格要活泼一点。」

AI 写出来：「姐妹们冲呀！！这款面霜真的绝绝子😭💕谁懂啊家人们，用完脸滑到打滑～」

它把"活泼"理解成了夸张叠词 + 满屏 emoji——可能根本不是你的活泼。

✓ 给一篇你的真范文

指令：「照这条的语气写——『换季脸干到起皮那几天，我靠它续了命。不浮夸，就是稳。』」

AI 写出来：「这阵子忽冷忽热，脸先扛不住。这支面霜我用得很安静，但确实没再起皮。」

它抓到了你的"克制、有画面、不喊口号"——因为它有了真样本可抄。

💡 记住这条：能给例子，就不要只给形容词。这一条贯穿整份教程——喂语料时、调试改稿时，都是它最听得懂的语言。

②要喂什么：五样东西（核心）

这是整件事的关键。喂得越具体，它越像你。下面五样，每样都给了"填空模板"，你照着填自己的内容就行。

① 范文：5–10 篇你最满意的稿子

挑你自己看了也满意、最能代表"这就是我"的稿子。不用多，5 到 10 篇就够，但每篇最好用一句话标注"我为什么满意"——这等于在帮 AI 划重点。

# 我的代表作（贴全文 + 标注） 范文1：【贴上你的稿子全文】 ↳ 我满意它：开头没废话，第二句就给画面 范文2：【贴上你的稿子全文】 ↳ 我满意它：结尾的 CTA 不硬，像朋友顺口提一句

② 语气画像：把"你怎么写"拆成可勾选的细节

这是说明书的核心。别写"我风格高级又亲切"这种虚的，拆成 AI 能照做的具体项：

语气：像跟懂行的朋友聊天，专业但不端着 句子长短：长短交替，常用短句单独成行制造节奏 人称：多用"你"，少用"我们" 标点 / emoji：少量 emoji，最多 1 个；不用感叹号轰炸 爱用的词：稳、扛得住、顺手、说实话、其实 绝不用的词：赋能、闭环、绝绝子、家人们、yyds 开头习惯：从一个具体场景切入，不喊口号 结尾习惯：轻轻收，CTA 像顺口一提，不强推

③ 受众 & 品牌背景：它替谁写、代表谁

品牌 / 产品：XX 面霜，主打温和修护 读者是谁：25–35 岁、护肤有点经验、烦透了夸张营销的女生 不能碰的红线：不能承诺疗效、不能用"医美级""根治"等违规词

④ 正反例：「我会这样写 / 我绝不这样写」

给一组对照，是帮 AI 划清边界最快的方式。

✓ 我会这样写

「换季那几天脸最诚实，干就是干。这支我用得安心。」

✕ 我绝不这样写

「姐妹们！！这款面霜真的封神了😭谁用谁知道，错过血亏！」

⑤ 任务说明：这次具体要它干啥

前面四样是"它是谁"，这一样是"这次干什么"。每次写新东西时补一句即可。

帮我写 3 条小红书标题 + 正文，推 XX 面霜的换季修护，每条 150 字以内，给我 3 个不同角度挑。
✅ 小结：①②③④ 是一次写好、长期复用的（存成你的"语气说明书"），⑤ 是每次现填的。下一节就教你把 ①②③④ 安到工具里，让它记住。

③怎么搭：把说明书安进工具（两个平台都讲）

目标是让工具记住你的说明书，这样你以后开新对话不用每次重贴。两个主流工具都能做到，选你顺手的一个就行。

⚠️ 开搭之前，先把第 ② 节那五样里的 ①②③④ 拼成一整段文字，存到记事本里。这段就是你的"语气说明书"，下面两个平台都要用它。

方式 A：ChatGPT —— 建一个「GPT」或用「项目」

ChatGPT 有两种存法，新手推荐先用「自定义指令」或「项目（Projects）」，最简单；想做得更正式、还能分享给同事，再建「GPT」。

  1. 最简单版（自定义指令）：点左下角你的头像 → 自定义 ChatGPT / Customize → 把你的"语气说明书"整段粘进去 → 保存。以后每次对话它都会自动带上。
  2. 进阶版（建 GPT）：左侧 探索 GPT → 创建 / Create → 在 Configure / 配置 里，把说明书贴进 "Instructions" → 把你的范文文件上传到 "Knowledge" → 起个名字（比如"小琪的文案分身"）→ 保存。
  3. 用项目（Projects）：新建一个 Project → 在项目设置里贴说明书、传范文 → 以后在这个项目里开的对话都自带它们。

方式 B：Claude —— 建一个「Project」

Claude 的 Project 很适合放长范文，对"还原长文风格"通常更稳。

  1. 登录 claude.ai → 左侧 Projects → 新建项目 / Create Project，起名"我的文案分身"。
  2. 找到项目里的 设置自定义指令 / Set custom instructions，把"语气说明书"整段贴进去。
  3. 把你的范文（②里的 5–10 篇）作为文件或文本，加到项目的 知识 / Knowledge 里。
  4. 以后要写东西，就在这个 Project 里开新对话，只补第 ②-⑤ 的"任务说明"那一句即可。
💡 两个平台是同一个套路：说明书贴进"指令"框，范文放进"知识/Knowledge"。记住这句话，按钮叫什么都不重要。

给你一份可以直接抄的「语气说明书」骨架

把橙色部分换成你自己的，整段贴进上面任一平台的"指令"框：

# 角色 你是我（一名护肤品牌的文案）的写作分身。你的任务是模仿我的语气写文案，让人看不出是 AI 写的。 # 我的语气画像 - 语气：像跟懂行的朋友聊天，专业但不端着 - 句子：长短交替，爱用短句单独成行 - 标点/emoji：克制，最多 1 个 emoji，不堆感叹号 - 爱用词：稳、扛得住、说实话、其实 - 禁用词：赋能、闭环、绝绝子、家人们、yyds、封神 - 开头：从具体场景切入，不喊口号 - 结尾：轻收，CTA 像顺口一提 # 受众与红线 - 读者：25–35 岁、烦透夸张营销的女生 - 红线：不承诺疗效，不用违规词 # 我会 / 绝不这样写（照这个边界来） - 会：「换季那几天脸最诚实，干就是干。」 - 绝不：「姐妹们这款真的封神了😭错过血亏！」 # 工作方式 - 我的范文在知识库里，写之前先读，模仿它们的节奏。 - 每次给我 2–3 个不同角度的版本让我挑。 - 拿不准我的偏好时，先问我一句，别自己脑补。

④怎么调试：像带新人改稿一样调到像

第一版几乎不会一步到位，这很正常。调试 = 让它写 → 你挑刺 → 它改 → 你把经验存回说明书。下面是具体怎么做。

第一步：先让它写，别急着评价

给它任务，让它出 2–3 版。先别夸也别否，带着下面这三个"尺子"去看：

尺子 1
开头像不像你？

你的开头通常怎么起？它是不是又喊口号了？

尺子 2
节奏像不像你？

句子长短、断句、有没有你那种停顿感？

尺子 3
有没有"AI 味"？

看下一节的黑名单，逐条对照。

第二步：怎么纠它——这是最容易做错的地方

新手最常见的纠法是丢一句"再活泼点 / 再高级点"，结果它越改越偏。原因和第①节一样：形容词它会脑补。要给它能照做的具体动作或例子。

✕ 模糊指令（它会乱猜）

「这版太硬了，再口语一点。」

「感觉不太像我，再改改。」

没有抓手，它只能瞎调，常常越改越远。

✓ 具体指令（它照着做）

「第一句太像广告，改成像范文3 那种从场景切入的开头。」

「『赋能肌肤』删掉，换成我会说的大白话，比如'让脸踏实下来'。」

指到具体句子 + 给方向/例子，它一次就能改对。

第三步：把好经验"存回去"，不然下次还犯

这一步最容易被忽略，却决定了它会不会"越用越像你"。当你发现一个反复要纠的毛病，别只在这次对话里纠——回到第③节那段说明书里补一条规则。

🔁 举个例子 你发现它老爱用"破折号——"来制造停顿，而你不喜欢。那就回到说明书的"禁用"那栏加一句：「不要用破折号制造停顿，改用句号断句。」下次开新对话，这个毛病就不会再犯了。调试的本质，是把改稿经验慢慢沉淀成一份越来越准的说明书。
✅ 一个好用的收尾动作：当它终于写出一篇你很满意的，把这篇加进范文库。范文越多、越新，它就越稳。

⑤常见坑 & 一眼认出「AI 味」

下面这些是新手最常踩的坑，和一份"机器腔黑名单"。把黑名单直接抄进你说明书的"禁用"栏。

「AI 味」黑名单（看到就改）

典型 AI 腔问题换成
赋能、助力、闭环、抓手、生态空洞的大词，没人这么说话具体的人话：帮你、让…更…
"在这个快节奏的时代…"万能废话开头，等于没说直接进具体场景
滥用破折号 —— 来 —— 断句一眼机器腔用句号、短句断
"不仅…而且…，更是…"排比工整到假，像八股口语化，长短句交替
每段都强行升华、喊口号收尾用力过猛，不真诚轻轻收，留白
emoji 和感叹号堆满像营销号，不像人克制，点到为止
⚠️ 坑 1：一次喂太多、太杂的范文。如果你的范文里风格不统一（有的端庄有的疯癫），它会被带乱。先只放"最能代表你"的一种风格。
⚠️ 坑 2：指望它读心。它不知道你脑子里的偏好，拿不准时它会脑补。在说明书里加一句"拿不准就先问我"，能少很多跑偏。
🚫 坑 3（重要）：AI 会"一本正经地编"。它可能编出不存在的功效、数据、case。涉及产品功效、价格、合规说法的，务必你自己核对一遍再发，别直接信。文案能模仿，事实要自己把关。

⑥速查清单：照着做一遍

把这一节当成贴在显示器边上的便利贴。

  1. 搜集：挑 5–10 篇你最满意的稿子，每篇标一句"为什么满意"。
  2. 写说明书：用第③节的骨架，填好语气画像 / 受众红线 / 正反例。
  3. 安进工具：说明书贴进"指令"框，范文放进"知识/Knowledge"（ChatGPT 建 GPT/项目，或 Claude 建 Project）。
  4. 先试写：给个真任务，让它出 2–3 版。
  5. 用三把尺子挑刺：开头像不像你 / 节奏像不像你 / 有没有 AI 味。
  6. 具体地纠：指到句子 + 给例子，别只说"再活泼点"。
  7. 存回去：反复要纠的毛病，回填进说明书的"禁用/规则"栏。
  8. 满意的入库：写出好稿就加进范文库，让它越用越像你。
  9. 发布前自己核对：功效、数据、合规说法，人来把关。
第一版搭出来只要半小时；真正"像你"，是靠第 ④ 步反复调出来的。慢慢来，不急。
